Q1: Why might we consider using Git?

Answer: We might use Git in order to be able to back up our work in case anything happens to our device, meaning that we will be able to recover it. Git also allows for 
collaborating with multiple people , creating new branches, maintaining a history which allows us to revert to past versions of code, and more.

Q3: What is the difference between Merging and Rebasing?

Answer: Merging creates a new commit that preserves the history of both branches, showing when branches diverged and merged. Rebasing rewrites commit history by 
applying commits from one branch onto another linearly, creating a cleaner history but changing commit SHAs. Merging is safer for shared branches; rebasing is better for 
local feature branches before merging.
